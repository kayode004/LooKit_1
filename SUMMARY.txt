================================================================================
                          QUICK START (5 MINUTES)
================================================================================

1. Copy all files from CODEBASE.md into the directory structure (FILE_TREE.md)

2. Setup credentials:
   - Supabase: Create account, run schema.sql, get API keys
   - Paystack: Create account, get test keys
   - GitHub: Create repository, push code

3. Local testing:
   npm install
   cp .env.example .env.local
   [Fill in .env.local with Supabase + Paystack keys]
   npm run dev
   → Visit http://localhost:3000

4. Deploy to Vercel:
   git push to GitHub
   Import repo in Vercel
   Add environment variables
   Deploy (2-3 minutes)
